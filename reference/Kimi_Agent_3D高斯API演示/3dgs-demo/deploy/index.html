Method Endpoint Description Auth

GET/api/v1/auth/meGet current user infoBearer

Run Locally

Get the full source code and run the complete stack on your machine

Terminal 1 - Backend 
# Navigate to backend
cd backend

# Create virtual environment
python -m venv venv
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Start FastAPI server
python main.py
# API docs at http://localhost:8000/docs
Terminal 2 - Frontend 
# Navigate to frontend
cd frontend

# Install dependencies
npm install

# Start dev server
npm run dev
# Open http://localhost:3000
Quick Test - Upload a Scene 
# 1. Register a user
curl -X POST http://localhost:8000/api/v1/auth/register \\
  -H "Content-Type: application/json" \\
  -d '{"username":"demo","email":"demo@test.com","password":"demo123"}'

# 2. Login to get token
curl -X POST http://localhost:8000/api/v1/auth/login \\
  -d "username=demo&password=demo123"

# 3. Upload a PLY scene
curl -X POST http://localhost:8000/api/v1/scenes \\
  -H "Authorization: Bearer <TOKEN>" \\
  -F "name=My Scene" -F "file=@scene.ply"
